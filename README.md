# 🛒 ShopEase - Online Store

ShopEase is a full-stack e-commerce web application developed as an academic project. The application provides users with a seamless online shopping experience through features like user authentication, product catalog browsing, shopping cart management, and database connectivity.

## 📌 Project Overview

The primary objective of this project is to simulate a real-world online shopping platform while applying concepts of front-end development, Java backend programming, database connectivity, and data handling using JSON and XML.

## ✨ Features

- 👤 User Registration and Login Authentication
- 🛍️ Product Catalogue
- 🛒 Shopping Cart
- 📦 Dynamic Product Rendering using JSON
- 🗂️ Product Data Management using XML
- 🔐 Java Servlet Authentication
- 💾 MySQL Database Connectivity using JDBC
- 📱 Responsive User Interface
- 📊 Organized Product Display
- 🔄 Session Management for User Login

## 🚀 How to Run

1. Clone this repository.

```
git clone https://github.com/your-username/ShopEase-Online-Store.git
```

2. Import the project into Eclipse or IntelliJ IDEA.

3. Configure Apache Tomcat Server.

4. Create a MySQL database.

5. Update the JDBC username and password in the Java Servlet.

6. Start the Tomcat Server.

7. Open your browser and visit:

```
http://localhost:8080/ShopEase/
```
